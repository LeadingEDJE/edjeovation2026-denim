pitch_deck.md or pitch_deck.pdf — Pitch Deck (Optional but Encouraged)

A 5–7 slide summary of your project. This is optional, but it helps judges quickly orient to your project before diving into the detailed documents.

Suggested slide structure:

1. Problem
2. Solution
3. How It Works (architecture or demo screenshot)
4. AI Usage Highlight
5. Business Value / ROI
6. Team

Submit as a PDF or a shareable link (Google Slides, Canva, etc.). If submitting a link, include it in a pitch_deck.md file.
