Demo Artifact

Show us what you built. The demo is your chance to make the solution tangible. Judges will use this to understand what the product actually does and how well it works.

Submit one of the following inside a demo/ subfolder:


* 🔗 Live Demo Link — A working URL with any credentials needed to access it
* 🎥 Recorded Demo Video — A screen recording walking through the key features (5 minutes max)
* 🖼️ Screenshots + Walkthrough — A demo_walkthrough.md file with annotated screenshots showing the key user flows

Tips for a strong demo:

* Show the happy path first, then any edge cases
* Narrate what is happening and why it matters
* If using a video, keep it under 5 minutes and get to the product quickly
* If using screenshots, include enough context that a judge who wasn't in the room can follow along
